# 🚩 CTF Writeups

A collection of my Capture The Flag (CTF) writeups, exploit scripts, and vulnerability research notes. 

My approach to security leans heavily into low-level systems, Linux internals, and manual exploitation. If you're looking for heavy reliance on automated frameworks, you won't find much of that here. Expect a lot of GDB, custom x86-64 assembly, and hand-crafted payloads.

## 🧠 Core Focus Areas

The writeups in this repository heavily emphasize manual exploitation and fundamental mechanics over automated frameworks:

    Binary Exploitation (Pwn): Stack frames, memory mapping manipulation, and runtime binary analysis using GDB/GEF.

    Web Security: Hand-crafting raw HTTP requests, state manipulation, and extracting data via direct SQL syntax execution.

    Linux Internals & PrivEsc: Abusing SUID misconfigurations, GTFOBins techniques, signal handling, and restricted shell escapes.

    Reverse Engineering: Raw disassembly inspection, stream parsing, and low-level control flow hijacking.
